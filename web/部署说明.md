# 部署到 Cloudflare（可选）

错题集是纯静态的，**不部署也能用**：

- 手机 App：不需要任何服务器，AI 请求走原生通道
- 电脑网页：`python3 serve.py 8090` 本地跑，顺手把 `/proxy` 也带上了

只有一种情况需要部署：你想把网页版挂到公网，让没装 App 的人也能打开。
下面是一个 Worker 同时托管静态资源和 `/proxy` 的做法（免费额度足够个人用）。

## 架构

```
<你的>.<子域>.workers.dev
├── /                 → dist/ 里的静态网页（Workers Static Assets）
├── /intro.html       → 介绍页
├── /packs/*.json     → 内置题库包
└── /proxy?u=...      → 转发 AI 请求（绕过 CORS）
```

页面和代理同源，所以网页版设置里的「代理地址」留空就行，不用填。

- 配置文件：`wrangler.toml`（`[assets] directory = "./dist"`）
- 代理代码：`worker.js`

## 发布

```bash
cd web

# 1. 组装 dist（只放要上线的文件）
rm -rf dist && mkdir dist
cp index.html intro.html manifest.json sw.js _headers \
   icon-192.png icon-512.png icon-maskable-512.png apple-touch-icon.png dist/
cp -r packs vendor dist/

# 2. 发布
npx wrangler deploy
```

十几秒后刷新网页就生效。第一次会让你 `wrangler login`。

> 改了 CSS/JS 记得把 `sw.js` 里的 `const VER = 'cuoti-v28'` 往上加一位，
> 否则老访客可能还在读 Service Worker 里的缓存。

## 登录踩过的坑

```bash
npx wrangler login --callback-port 8976
```

- 它打印的授权链接**有效期约 2 分钟**，页面加载慢就超时，得重来
- 提示 `Failed to open a browser` 是正常的，手动把链接粘到浏览器即可
- 授权页的 **Authorize 按钮可能被浏览器底栏挡住**，往上滑一点才露出来
- 授权成功后 wrangler 会自己退出（exit 0）

## 账号侧一次性设置

1. **邮箱验证**：没验证时部署会报 `code: 10034`
2. **workers.dev 子域名**：没注册会报 `You need to register a workers.dev subdomain`
3. **免费额度**：Workers 每天约 10 万请求，静态资源访问不计费

## 安全

- 代理有**域名白名单**（`worker.js` 顶部 `ALLOW_HOSTS`），不在名单里直接 403
- 不保存、不记录任何 API Key，请求头原样透传
- 页面里的 Key 存在各人自己的浏览器 IndexedDB 里，服务端不存
- 想加限流：控制台建 KV 命名空间 → 在 `wrangler.toml` 里绑定为 `RATE` → 重新 deploy，
  自动变成「每 IP 每天 300 次」

## 注意

`worker.js` 里的 `*` 跨域是给「网页版直连」用的。如果你把代理公开给别人用，
记得把 `Access-Control-Allow-Origin` 收窄到你自己的域名，否则会变成一个开放的 LLM 代理。
