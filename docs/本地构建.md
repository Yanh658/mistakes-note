# 在 Windows 上构建 APK

> Linux / macOS 上直接 `./gradlew assembleDebug` 就行，基本不会遇到下面这些问题。
> 这份文档主要是给 Windows 用户看的，尤其是**用户名是中文**的情况。

## 环境

- JDK 17
- Android SDK：`platforms;android-35`、`build-tools;35.0.0`、`platform-tools`
- Gradle：仓库自带 wrapper（8.7），不用自己装

最省事的是装 Android Studio，它会把 JDK 和 SDK 一起装好；然后用 Android Studio
打开 `android/` 目录即可。

命令行构建：

```bash
cd android
# Windows PowerShell
$env:ANDROID_HOME = "$env:LOCALAPPDATA\Android\Sdk"   # 改成你的 SDK 路径
./gradlew assembleDebug

# macOS / Linux
export ANDROID_HOME=$HOME/Library/Android/sdk
./gradlew assembleDebug
```

产物：`android/app/build/outputs/apk/debug/app-debug.apk`

## 中文用户名会踩的三个坑

如果 `C:\Users\张三\...` 这种路径里有中文，AGP 和 JDK 会各有各的意见。

### 坑 1：AGP 直接拒绝构建

```
Your project path contains non-ASCII characters. This will most likely cause the build to fail on Windows.
```

加 `android.overridePathCheck=true` 只能让它闭嘴，后面 `aapt2` 照样可能出问题。
干净的做法是用**目录联接**给它一条纯 ASCII 路径：

```powershell
cmd /c mklink /J C:\cuoti-build "D:\code\cuoti"
cd C:\cuoti-build\android
.\gradlew assembleDebug
```

junction 不是复制，改的还是同一份文件，两边不会不同步。

### 坑 2：`~/.android` 写不进去

部分环境（受限账户、沙箱）里，AGP 会往 `C:\Users\<中文名>\.android` 写分析文件、
往临时目录写中间产物，然后报 `AccessDenied` / `NoSuchFileException`。
把它们重定向到工作目录里就行：

```powershell
$env:ANDROID_USER_HOME = "D:\build\android-home"
$env:GRADLE_USER_HOME  = "D:\build\gradle-home"
$env:TMP = "D:\build\tmp"; $env:TEMP = "D:\build\tmp"
$env:JAVA_TOOL_OPTIONS = "-Duser.home=D:\build\android-home -Djava.io.tmpdir=D:\build\tmp -Dfile.encoding=UTF-8"
```

### 坑 3：`gradle.properties` 里别写 Linux 路径

`-Djavax.net.ssl.trustStore=/etc/ssl/certs/java/cacerts` 这种在 Windows 上指向不存在的文件，
SSL 会直接失败。仓库里的 `gradle.properties` 已经清掉了，别再抄回来。

## 改了网页之后

`web/` 是源，`android/app/src/main/assets/` 是它的副本（不包含 `serve.py`、`worker.js`、
`wrangler.toml`、`_headers`、`部署说明.md` 这几个只给服务器用的文件）。同步：

```powershell
$w = '.\web'
$a = '.\android\app\src\main\assets'
$skip = @('serve.py','worker.js','wrangler.toml','_headers','部署说明.md')
Get-ChildItem $w -Recurse -File | Where-Object { $skip -notcontains $_.FullName.Substring($w.Length+1) } |
  ForEach-Object {
    $rel = $_.FullName.Substring($w.Length+1)
    New-Item -ItemType Directory -Path (Split-Path (Join-Path $a $rel)) -Force | Out-Null
    Copy-Item $_.FullName (Join-Path $a $rel) -Force
  }
```

改网页记得同步三处版本号：`index.html` 里的 `APP_VER`、`version.json`、`sw.js` 里的 `VER`。

## 出包前校验

```powershell
$bt = "$env:ANDROID_HOME\build-tools\35.0.0"
& "$bt\aapt2.exe" dump badging app\build\outputs\apk\debug\app-debug.apk | Select-String "^package:|launchable-activity"
& "$bt\apksigner.bat" verify --print-certs app\build\outputs\apk\debug\app-debug.apk
```
